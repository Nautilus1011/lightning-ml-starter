# Project Guardrails — lightning-ml-starter

このリポジトリで特に外してはいけない制約です。

## やってはいけないこと

### データと成果物

- `data/`、`outputs/`、`workspace/` の中身をコミットしない
- 学習済み重み、推論結果の画像、ログを Git 管理に追加しない
- `.env` や W&B の API キーをコミットしない。ログやドキュメントにも書かない

### 研究品質

- 実行していない学習や検証を、実施済みとして記載しない
- データリークのある評価結果を正しい結果として扱わない
- 学習を途中で止めた結果を、最後まで回した結果として報告しない

### テンプレートとしての品質

- `README.md` と `docs/` に書かれた手順を壊さない。コマンドや設定を変えたらドキュメントも更新する
- 初学者が読む前提を崩さない。説明なしに高度な抽象化やツールを持ち込まない
- Docker 以外の環境でしか動かない変更を入れない

### コード運用

- `main` に直接コミットしない
- PR をマージしない（マージはユーザーが行う）
- 絶対パスを増やさない

## GitHub 運用

- Issue と PR は `.github/` のテンプレートに従う
- 実行できなかった検証は PR に書く
